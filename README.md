## 📌 Project Overview
This project performs an exploratory data analysis, data profiling, and structured data cleansing pipeline on the Sri Lankan G.C.E. Advanced Level (A/L) 2020 examination dataset (`2020_al_data_kaggle_upload_new_old_syllabi.csv`).

The primary objectives for **Day 03** are:
1. Identifying and profiling elite student performance (specifically analyzing students who achieved **3 'A' passes** across their main subjects per stream).
2. Implementing an end-to-end data cleaning and standardization routine to resolve structural and semantic anomalies in raw examination records.
